# Gestionale Repub

App per i costi del Repub: prodotti, ricette di drink e cucina, fatture elettroniche e foto di fatture, magazzino, fornitori, ordini, scadenze, vendite, mappa del menu, simulatore, eventi e costo dell'olio.

Questa è la versione di prova con alcuni prodotti e ricette presi dal foglio «Drink & food cost repub 2024-25-26». I dati sono salvati sul dispositivo; il collegamento a Firebase arriverà dopo.

File principali:
- `index.html`, `stile.css`, `app.js`: l'app
- `motore.js`: i calcoli (costi, ricette, lettura delle fatture)
- `dati.js`: i dati di partenza della prova e le due fatture di esempio
